# Mockups

Standalone HTML mockups of planned birddog screens. They use example data and save nothing.

| Mockup | What it shows |
|---|---|
| [documents/](documents/index.html) | Documents tab: curation grid, editor panel, process-code actions, role-based filters |

To view one, open its `index.html` in a browser (double-click, or `open mockups/documents/index.html`).
GitHub shows the source rather than the page; use GitHub Pages or a local copy to see it rendered.

This directory is excluded from Elastic Beanstalk deploys (`.ebignore`).
